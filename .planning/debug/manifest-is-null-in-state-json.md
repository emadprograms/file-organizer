# Debug Session: manifest is null in state.json

## Symptoms
- **Expected behavior**: The `manifest` field inside `_state.json` files should not be `null`.
- **Actual behavior**: Safra C (53/53 houses) and Safra Flats (77/77 houses) have `manifest=null`. Safra D (0/48) does not.
- **Error messages**: N/A
- **Timeline**: Occurs in `_state.json` files generated by the ingest pipeline.
- **Reproduction**: Run ingest on a new house (first-time, non-prepend mode). Inspect `_state.json`.

## Current Focus
- hypothesis: Bug in `src/ingest/core.py` non-prepend else branch — `run_reconciliation` writes manifest via its own State instance, but the local `state` object is saved without reloading, so manifest stays null.
- next_action: Fixed.

## Resolution
- **root_cause**: In `src/ingest/core.py` lines 358–374, the non-prepend save path saves `state` after `run_reconciliation`, but `run_reconciliation` writes the manifest to a *separate* `State` instance internally. The local `state` object is never reloaded, so its `manifest` field stays `None`. This matches `run_generation_pass` which explicitly calls `state.load()` after `run_reconciliation` at line 283 — the ingest path forgot to do the same.
- **fix**: Added `state.load()` before the final `state.save()` in the non-prepend else branch of `src/ingest/core.py`, mirroring the pattern in `run_generation_pass`.
- **files_changed**: src/ingest/core.py

## Findings
- `src/ingest/core.py` was generating `{"summary": ..., "per_page": ...}` and putting it in `state.data["routed_documents"]`.
- The actual list of routed DocumentGroups was effectively discarded instead of being saved.
- `src/reconcile/core.py` was relying on this bug by trying to load `routed_documents` as a dict with `per_page` array. 
- I fixed `ingest/core.py` to correctly map the manifest dictionary to `state.data["manifest"]`, and properly map the list of `DocumentGroup` objects to `state.data["routed_documents"]`.
- I fixed `reconcile/core.py` to correctly load from `state.data["manifest"]` but also built in legacy fallback capabilities so existing un-migrated states continue to work.
- I fixed all 16 affected test suites across the repository to assert against the corrected `manifest` payload instead of the old buggy behavior.
