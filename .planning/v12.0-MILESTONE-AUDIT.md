## 3. Cross-Phase Integration & E2E Flows

1. **Zero-AI Manual Ingestion Flow**:
   - Scanned PDF is uploaded via `POST /api/ingest` with `mode=manual`.
   - File is registered and archived into `{area}/{house}/batches/batch_{id}_{filename}` with exact page count verified via PyMuPDF.
   - Document record is committed to SQLite `documents` with `is_manual=1`, notes, and target metadata.
   - Master PDF is saved to `{area}/{house}/vault/doc_{vault_id}.pdf`.
   - `pages` records are linked with page inheritance: page 1 has `is_continuation=0` and document title/subject; subsequent pages have `is_continuation=1` inheriting category, tenant, and date.
   - Verified end-to-end in `test_v12_e2e_manual_ingest_lifecycle`.

2. **AI Preview Endpoint (Zero Mutations)**:
   - Evaluates scanned PDF heuristics (Arabic contract keywords, dates, tenant names, house numbers).
   - Generates suggested metadata for client-side auto-fill.
   - Guaranteed ZERO writes: 0 database rows created, 0 filesystem artifacts written.
   - Verified end-to-end in `test_v12_e2e_preview_ai_zero_mutations`.

3. **Search & Real-Time Discovery**:
   - Ingested manual documents are immediately indexable and retrievable via `/api/search` by Arabic title and page content explanation.
   - Newly created documents reflect instantaneously on `/api/areas/{area}/houses/{house}/timeline` and `/api/areas/{area}/houses/{house}/categories`.

4. **UI Interaction & Ingest Station Drawer**:
   - `+ Ingest` button and `⌘I` / `Ctrl+I` keyboard shortcuts open drawer.
   - Fullscreen drag-and-drop activates contextual target prompts based on selected Area / House.
   - Mode switcher provides clean UI separation between Single Document Manual/Assisted and Multi-Document Batch Auto-Split.
   - Real-time refresh triggers without requiring full page reload.
