# Phase 112: House Settings Modal & Ingestion Badging - Plan

**Phase:** 112
**Goal:** Enable adding and editing applicants in the House Settings modal with Resident/Applicant toggle; badge applicants in Ingest Station and Batch Move/Copy dropdowns; display applicant badges in Timeline View and Command Palette search results.
**Requirements:** SET-01, ING-01, TIM-01

---

## Tasks

### Task 1: Backend Timeline DTO & Query Support (TIM-01)
- In `src/HousingApplication.Web/Models/DTOs.cs`:
  - Add `[JsonPropertyName("is_resident")] public int IsResident { get; init; } = 1;` to `TimelineItemDto`.
- In `src/HousingApplication.Web/Data/FileOrganizerRepository.cs`:
  - In `GetTimelineAsync`: select `COALESCE(t.is_resident, 1) AS IsResident`, include in row tuple, and set `IsResident = row.IsResident` on `TimelineItemDto`.

### Task 2: House Settings Modal Resident / Applicant Toggle (SET-01)
- In `src/HousingApplication.Web/wwwroot/js/tenant-manager.js`:
  - Add `.tenant-type-select` to each tenant row in `addTenantRow(t)`:
    `<select class="tenant-type-select ..."><option value="resident">🏠 Resident • مقيم</option><option value="applicant">📋 Applicant • متقدم (لم يسكن)</option></select>`
  - Wire change listener on `.tenant-type-select`:
    - When `applicant`:
      - Uncheck and disable `.tenant-present-check`.
      - Clear and disable `.tenant-end-input` (`bg-slate-100 text-slate-400 cursor-not-allowed`).
      - Set `.tenant-start-input` title and placeholder to `Application / Order Date • تاريخ التخصيص/الطلب`.
    - When `resident`:
      - Enable `.tenant-present-check`.
      - Enable `.tenant-end-input` (unless Present is checked).
      - Set `.tenant-start-input` title to `Start Date • تاريخ البدء`.
  - Add notes input/field `.tenant-notes-input` to support editing `notes`.
  - In `saveTenantsAndReallocate`:
    - Set `is_resident: typeSelect.value === 'applicant' ? 0 : 1`.
    - Set `notes: notesInput ? notesInput.value.trim() || null : null`.
- In `src/HousingApplication.Web/wwwroot/index.html`:
  - Update table headers in `#tenant-modal` to include `Type • النوع` column.

### Task 3: Ingest Station & Batch Dropdown Badging (ING-01)
- In `src/HousingApplication.Web/wwwroot/js/ingest-station.js`:
  - In `populateHousebatchTenantSelect` and `populateTenants`:
    - If `t.is_resident === 0 || t.is_resident === false`, label option as `📋 ${t.name} (متقدم - لم يسكن)`.
  - In `resolveLatestTenant`:
    - Filter `candidates = residentTenants.length > 0 ? residentTenants : tenants;` before searching active tenants.
- In `src/HousingApplication.Web/wwwroot/js/categories-view.js`:
  - In `formatBatchTenantLabel(t)`:
    - If `t.is_resident === 0 || t.is_resident === false`, return `📋 ${t.name || 'Applicant'} (متقدم - لم يسكن)`.

### Task 4: Timeline View & Command Palette Badging (TIM-01)
- In `src/HousingApplication.Web/wwwroot/js/timeline-view.js`:
  - When rendering document cards, if `doc.is_resident === 0 || doc.is_resident === false`, render purple applicant badge for the tenant tag:
    `<span class="bg-purple-50 text-purple-700 px-2 py-0.5 rounded-md font-medium text-[10px] border border-purple-200 truncate max-w-[140px] flex items-center gap-1" title="متقدم (لم يسكن)"><span class="w-1.5 h-1.5 rounded-full bg-purple-500"></span>${escapeHtml(doc.primary_tenant || 'No Tenant')}</span>`
- In `src/HousingApplication.Web/wwwroot/js/command-palette.js`:
  - When rendering tenant search result, if `t.is_resident === 0 || t.isResident === 0 || t.is_resident === false`:
    - Apply purple theme: `avatar: 'bg-purple-50 text-purple-600 ...'`, `badge: 'text-purple-700 bg-purple-50 border border-purple-300'`.
    - Render `📋` icon in avatar box.
    - Set extra info to `📋 متقدم (لم يسكن)` or `طلب تخصيص`.

### Task 5: Automated Tests & Verification
- In `tests/frontend/components/house_settings_modal.test.js`:
  - Add tests verifying:
    - Selecting `applicant` disables Present checkbox and End Date input.
    - Adding applicant saves `is_resident: 0` in payload.
    - Loading tenant with `is_resident: 0` preselects Applicant type and disables End Date.
- In `tests/frontend/components/ingest_station.test.js` or `batch_operations.test.js`:
  - Add tests verifying applicant options contain `📋` and `(متقدم - لم يسكن)`.
- In `tests/frontend/components/command_palette_tenants.test.js`:
  - Add test verifying applicant search result displays purple applicant styling and `📋`.
- Run `npm run test:frontend` and `export PATH="$HOME/.dotnet:$PATH" && dotnet test HousingApplication.sln`.
