# Phase 117: Login Screen, Session Management & Navbar User Profile — Plan 01

## Goal
Implement a polished, responsive, bilingual login screen overlay with user picker & manual password entry, an active user session state manager in frontend, top navbar user indicator with avatar and role badges (`صلاحيات كاملة • Full Access` vs `قراءة ورفع فقط • Read & Upload`), and a smooth logout workflow.

## Requirements Covered
- **UI-01**: Dedicated `#login-screen` modal/overlay with bilingual styling (Arabic RTL primary, English secondary), quick user-select chips/dropdown for the 10 seeded users, password field, and clear error display.
- **UI-02**: Frontend Auth Manager (`auth-manager.js`) to handle `/api/auth/me`, `/api/auth/login`, `/api/auth/logout`, storing user/role state in memory/localStorage and dispatching `auth:state-changed` events.
- **UI-03**: Top navbar user profile section:
  - User avatar with initials or icon
  - Display name (e.g., Emad, Nawaf, etc.)
  - Clear role badge (`صلاحيات كاملة` / `قراءة ورفع فقط`)
  - Dropdown / Logout button
  - Fast user-switch option or logout button
- **VER-02**: Vitest unit/component tests for `auth-manager.js` and login/navbar UI components.

## Proposed Changes
1. **HTML (`src/HousingApplication.Web/wwwroot/index.html`)**:
   - Add `#login-screen` overlay before the main app or as a full-screen gatekeeper modal when unauthenticated.
   - Include user selector buttons/grid or select dropdown with all 10 users grouped by role (4 Full Access, 6 Read & Upload).
   - Include password input with show/hide toggle and prefilled demo hint (`password123`).
   - Add `#user-profile-menu` inside the top navbar `#main-nav` next to the archive export / settings / help buttons.
2. **JavaScript (`src/HousingApplication.Web/wwwroot/js/auth-manager.js`)**:
   - Class `AuthManager` or singleton `window.authManager`.
   - Methods: `init()`, `checkSession()`, `login(username, password)`, `logout()`, `getCurrentUser()`, `hasDeletePermission()`, `isAdmin()`, `isContributor()`.
   - Expose global event `auth:user-changed`.
3. **CSS / Styling**:
   - Ensure clean Tailwind/custom styles for login screen and top navbar user card.
4. **Sync with `dist/win-x64/wwwroot/`**:
   - Keep both `src/` and `dist/` in sync.
5. **Vitest Tests (`tests/web/components/auth_manager.test.js`)**:
   - Unit tests for session check, login, logout, permission query, role evaluation.
