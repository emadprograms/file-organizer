# Phase 118: Role-Based UI Action Controls & Delete Restriction Enforcement — Plan 01

## Goal
Enforce role-based access control across all frontend interfaces, hiding or disabling all delete triggers for Contributor users (`Nawaf`, `Naseem`, `Mulla`, `Mariam`, `Shaima`, `Mona`), ensuring they only have Read and Upload capabilities. Only Admin users (`Emad`, `Bubshait`, `Ehtezaz`, `Mustafa`) will see delete controls.

## Requirements Covered
- **PERM-01**: Hide 3-dots menu "Delete Document" action across Folders and Timeline views for Contributor users.
- **PERM-02**: Hide "Delete Selected" button on `#batch-action-bar` during multi-select for Contributor users.
- **PERM-03**: Hide 1-tap page delete buttons on thumbnail cards and "Delete Selected Pages" in Document Page Editor for Contributor users.
- **PERM-04**: Hide Danger Zone / Delete House controls in House Settings Modal for Contributor users.
- **VER-02**: Comprehensive Vitest component tests verifying all delete controls are hidden for Contributors and visible for Admins.

## Implementation Steps
1. In `src/HousingApplication.Web/wwwroot/js/categories-view.js` and `timeline-view.js`:
   - Check `window.authManager?.hasDeletePermission()`.
   - In document 3-dots menu rendering, omit or conditionally hide the Delete Document item if user cannot delete.
   - In `#batch-action-bar` rendering / updating, hide `#btn-batch-delete` for Contributors.
2. In `src/HousingApplication.Web/wwwroot/js/doc-page-editor.js`:
   - When rendering page thumbnails, conditionally hide the page delete button (`.btn-delete-page`).
   - In the sticky bottom toolbar, hide `#btn-editor-delete-selected` if `!window.authManager?.hasDeletePermission()`.
3. In `src/HousingApplication.Web/wwwroot/js/house-settings-modal.js`:
   - Check permissions when opening modal; hide `#danger-zone-section` or `#btn-delete-house` for Contributors.
4. Listen to `auth:user-changed` event across views so if a user switches account, the UI dynamically re-renders or updates delete button visibility immediately.
5. Synchronize all modified files to `dist/win-x64/wwwroot/js/`.
6. Add Vitest tests in `tests/web/components/rbac_ui_enforcement.test.js` validating that all delete options are hidden for Contributors and visible for Admins.
