# Plan 109-01: Pure .NET Core Architecture & Python Elimination

## Goal
Completely remove Python dependencies, reorganize the codebase into an idiomatic ASP.NET Core 8.0 solution (`src/HousingApplication.Web/`, `tests/HousingApplication.Tests/`, and `tests/frontend/`), link projects in `HousingApplication.sln`, update Vitest static imports to the real web root, update `run-mac.sh` and `package.json`, and verify 100% test pass rate with zero Python runtime.

## Requirements Covered
- **ARCH-01**: Remove all legacy Python source files (`src/` Python files, `.venv/`, `requirements.txt`, `patch_index.py`, and Python pytest files in `tests/`).
- **ARCH-02**: Reorganize ASP.NET Core 8.0 project from `web-net/` into `src/HousingApplication.Web/` with `HousingApplication.sln`.
- **ARCH-03**: Consolidate test suites under `tests/` (`tests/HousingApplication.Tests/` for xUnit and `tests/frontend/` for Vitest).
- **ARCH-04**: Update all Vitest frontend test imports across `tests/frontend/` to load static assets directly from `src/HousingApplication.Web/wwwroot/js/`.
- **ARCH-05**: Update `run-mac.sh`, `package.json`, and deployment configs, verifying all 148 backend tests and 277 frontend tests pass 100%.

## Tasks
1. Update all test file paths in `tests/frontend/` to import scripts from `src/HousingApplication.Web/wwwroot/js/` and HTML from `src/HousingApplication.Web/wwwroot/index.html`.
2. Move ASP.NET Core project from `web-net/` to `src/HousingApplication.Web/`:
   - Rename project file to `HousingApplication.Web.csproj`.
   - Move `web-net/FileOrganizer.Tests/` to `tests/HousingApplication.Tests/`, rename to `HousingApplication.Tests.csproj`, and update project reference to `../../src/HousingApplication.Web/HousingApplication.Web.csproj`.
   - Remove `web-net/` directory.
3. Remove legacy Python code:
   - Remove all Python files and directories from the old `src/` (keeping only `src/HousingApplication.Web/`).
   - Remove `.venv/`, `requirements.txt`, `patch_index.py`, `config_test_v11.yaml`, and Python test files in `tests/` (`test_*.py`, `tests/db/`, `tests/pipeline/`).
