# Phase 56: Idempotency Guarantee - Summary

## Decisions Made
- **File Timestamp Validation:** We opted to enforce strict `mtime` preservation across idempotent operations. This meant replacing bulk folder deletions (such as for `[Timeline View]`) with selective synchronization logic.
- **`state.json` Determinism:** We recognized that `state.json` drifts occurred largely due to how intermediate objects (like newly adopted ghosts or raw PDFs) were flushed to the system vs how they were loaded from a cold-start. We decided to recompute internal mapping (such as `g.shortcuts`) uniformly right before the `state.json` save operation to enforce zero-state divergence.

## Lessons Learned
- **Left-To-Right Markers (`\u200E`) matter:** The most elusive bug encountered involved `cleanup` logic indiscriminately deleting valid tenant folders. The root cause was a mismatch in folder names: the test suite named the folder `"Test Tenant (2021 - 2025)"` while the application (by design, to avoid Arabic RTL rendering issues) named it `"Test Tenant \u200E(2021 - 2025)\u200E"`. When doing exact directory matching, invisible characters will silently cause failures if tests aren't using the exact canonical generators. 
- **The importance of tracking side-effects:** Writing tests for idempotency forces the architecture to become purely data-driven. Previously, timeline regeneration assumed it was the only actor in the folder and brute-force deleted everything. Changing this to stateful synchronization logic reduced file I/O operations significantly.

## Patterns
- **Idempotent Synchronization:** We used `batch_read_shortcut_targets` (via Windows Shell) to deeply inspect the target of existing `.lnk` files before choosing to rewrite them. This allows fast, bulk verification of existing file system state against the desired memory state.
- **Byte-for-Byte Assertion:** In integration testing, capturing the entire JSON file as a string and doing a direct text diff provides the most powerful proof of deterministic data structures.

## Surprises
- Even after enforcing JSON equality, a discrepancy remained because the `timeline` regeneration used the old relative paths inside the `g.shortcuts` instead of the newly shifted paths generated by the reconciler. This highlights that when objects mutate during a pipeline, all subsequent sub-systems must be fed the finalized values, not the transient intermediate values.
