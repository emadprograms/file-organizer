# Phase 116: User Data Model, Password Security & Auth API — Plan 01

## Goal
Implement SQLite user data models, cryptographic password hashing, automated seeding of 10 users with roles, cookie-based session authentication endpoints (`/api/auth/login`, `/api/auth/logout`, `/api/auth/me`, `/api/auth/users`), and backend 403 Forbidden RBAC protection on all deletion endpoints for Contributor users.

## Requirements Covered
- **AUTH-01**: SQLite users table schema and migrations in DatabaseInitializer
- **AUTH-02**: Seed 10 predefined users on startup (4 Admins: Emad, Bubshait, Ehtezaz, Mustafa; 6 Contributors: Nawaf, Naseem, Mulla, Mariam, Shaima, Mona)
- **AUTH-03**: Secure session/cookie authentication endpoints
- **AUTH-04**: Fast login switch/preset support via `/api/auth/users`
- **RBAC-01**: Single doc delete returns 403 for Contributors
- **RBAC-02**: Batch doc delete returns 403 for Contributors
- **RBAC-03**: Page editor delete returns 403 for Contributors
- **RBAC-04**: House delete returns 403 for Contributors
- **VER-01**: Comprehensive xUnit tests verifying auth, seeding, and RBAC enforcement

## Implementation Steps
1. Create `src/HousingApplication.Web/Models/User.cs` with `User`, `UserDto`, `LoginRequestDto`, `LoginResponseDto`.
2. Create `src/HousingApplication.Web/Common/PasswordHasher.cs` with PBKDF2 hashing and verification.
3. Update `src/HousingApplication.Web/Data/DatabaseInitializer.cs` to create `users` table and seed the 10 users if table is empty.
4. Update `src/HousingApplication.Web/Data/IFileOrganizerRepository.cs` and `FileOrganizerRepository.cs` with user retrieval and seeding methods.
5. Update `src/HousingApplication.Web/Program.cs`:
   - Register Cookie Authentication and Authorization services.
   - Add auth endpoints: `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/me`, `GET /api/auth/users`.
   - Add `IsRestrictedFromDelete(HttpContext)` helper and guard all 5 deletion endpoints with 403 Forbidden.
6. Create `tests/HousingApplication.Tests/AuthAndRbacTests.cs` with unit and integration tests.
7. Run tests to confirm 100% pass.
