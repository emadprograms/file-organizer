# Plan 114-01: Settings Modal Simplification & Applicant Clean-Up

## Objective
Remove redundant notes inputs from the tenant management modal, rebalance the table grid to a clean 12-column layout, remove notes display badges from applicant cards in the House Profile, and safeguard backend vacated tenant validation so applicants are explicitly exempt.

## Execution Steps

1. **Update House Settings Table Header in `index.html`**:
   - Remove the `Notes` column header.
   - Rebalance grid columns to 12 spans: Name (4), Type (2), Start Date (2), End Date (2), Present (1), Delete (1).

2. **Update Tenant Row Template and Handlers in `tenant-manager.js`**:
   - Remove `.tenant-notes-input` and its container div from `addTenantRow`.
   - Rebalance row grid columns to match the 12-span header.
   - Update `handleSaveTenants` to omit notes from the save payload.

3. **Clean Up Applicant Card in `house-profile.js`**:
   - Remove `notesHtml` and `.applicant-notes` element from the applicant card markup.

4. **Safeguard Vacated Date Conflict in `Program.cs`**:
   - Explicitly require `resolvedTenant.IsResident == 1` in the date conflict condition so applicants never trigger vacated warnings.

5. **Update and Run Test Suites**:
   - Update `tests/web/components/house_settings_modal.test.js` and `tests/web/components/applicant_workflow.test.js`.
   - Run `dotnet test` and `npm run test:web` to verify 100% test pass.
