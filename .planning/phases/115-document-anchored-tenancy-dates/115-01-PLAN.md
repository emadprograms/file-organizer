# Plan 115-01: Document-Anchored Tenancy Dates & Minimalist Register

## Objective
Eliminate manual start date entry and timeline conflicts by automatically anchoring tenant and applicant start dates to their earliest document date (`MIN(primary_date)`). For new tenants with zero documents, display "Auto (on first upload)" until the first file is uploaded. Keep the end date user-decided (Present vs. vacate/closing date). In the House Profile, streamline the register into a clean, minimalist layout: Tenants at the top, a single divider line, and Applicants at the bottom with simple one-word labels.

## Execution Steps

1. **Backend Earliest-Document Start Date Derivation (`FileOrganizerRepository.cs` & `Program.cs`)**:
   - In `GetHouseProfileAsync` and `GetTenantsAsync`, query `MIN(primary_date)` for each tenant's visible documents. If documents exist, resolve the effective start date to this earliest date.
   - In `/api/ingest` upload endpoint, if a tenant has no start date or the newly ingested document is dated earlier than the current start date, update the tenant's start date automatically.
   - For tenants with zero documents, represent start date as `null` or empty so the UI can display "Auto (on first upload)".

2. **House Settings Modal (`tenant-manager.js`)**:
   - Update `addTenantRow` so the Start Date field displays the auto-anchored date or the placeholder `Auto (on first upload)`.
   - Ensure the End Date field and Present checkbox remain fully interactive and user-decided.
   - Maintain 12-column grid and two-way Resident $\leftrightarrow$ Applicant switching.

3. **House Profile Minimalist Register (`house-profile.js`)**:
   - In `renderHouseProfile`, structure the tenant area cleanly:
     - Residents section at top with simple title: `المستأجرون` (Tenants).
     - Exactly 1 subtle divider line separating residents from applicants.
     - Applicants section at bottom with simple title: `المتقدمون` (Applicants).
     - Remove wordy explanatory subtitles and redundant phrases.

4. **Testing & Autonomous Verification**:
   - Add backend tests in `RepositoryTests.cs` / `ApiEndpointTests.cs` verifying earliest document start date derivation and 0-document edge case.
   - Update web Vitest tests in `house_settings_modal.test.js`, `house_profile.test.js`, and `applicant_workflow.test.js`.
   - Run both test suites to verify 100% pass rate.
