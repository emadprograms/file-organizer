# Plan: Phase 84 - Core Navigation & Routing

## 1. Backend: Hierarchical Data API
- Add a new endpoint `/api/tree` in `src/api/routes.py` and `src/api/models.py`.
- The tree should represent `Areas` -> `Houses` -> `Tenants`.
- `Areas` are directories in `areas_root`.
- `Houses` are directories inside `Areas`.
- `Tenants` are derived from `[house_id]_state.json` (`grouped_documents`'s `primary_tenant` fields).
- Add `pytest` test in `tests/test_api.py` for `/api/tree`.

## 2. Frontend: Vanilla JS Sidebar & Routing
- Update `src/web/app.js` to fetch from `/api/tree` and render a collapsible sidebar.
- Levels: Area -> House -> Tenant.
- Implement UI interactions (expand/collapse clicks).
- Implement routing logic using hash-based routing (e.g. `#/area/Area_A/house/House_1/tenant/Ali`).
- When a hash changes, automatically expand the sidebar to highlight the selected tenant.

## 3. Testing
- Write Playwright E2E tests in `tests/frontend/test_navigation.py` to verify:
  - Sidebar renders the 3 levels.
  - Expand/collapse functions correctly.
  - Deep linking expands the tree properly on load.
