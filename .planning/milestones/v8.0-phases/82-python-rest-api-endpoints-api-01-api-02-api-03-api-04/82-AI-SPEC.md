## 1. System Classification

**System Type:** Hybrid (REST API + Structured Data Extraction / Autonomous Agent)

**Description:**
A Python-based REST API that exposes endpoints (API-01 to API-04) for file organization. It integrates an AI layer to classify, parse, and route files based on content, providing reliable and structured responses to frontend or CLI clients.

**Critical Failure Modes:**
1. Incorrect file classification leading to data loss or misplacement.
2. API timeouts or latency spikes during AI model inference.
3. Unhandled exceptions from the AI provider failing the entire request.

## 2. Framework Decision

**Selected Framework:** FastAPI + OpenAI Agents SDK

**Version:** fastapi>=0.100.0, openai>=1.0.0

**Rationale:**
FastAPI provides the fastest, most reliable way to build Python REST APIs with built-in Pydantic validation. The OpenAI Agents SDK is chosen for the AI layer because it offers the simplest path to a working agent for structured data extraction and classification with built-in tracing, and the project is expected to prioritize speed to a working prototype.

**Alternatives Considered:**

| Framework | Ruled Out Because |
|-----------|------------------|
| LangChain | Abstraction overhead is too high for simple REST API wrappers |
| LlamaIndex | Primary use case is not RAG; it's classification and API wrapping |

**Vendor Lock-In Accepted:** Yes (OpenAI is acceptable for rapid development; abstraction can be added later).

## 3. Framework Quick Reference

> Fetched from official docs by `gsd-ai-researcher`. Distilled for this specific use case.

### Installation
```bash
pip install fastapi uvicorn openai pydantic
```

### Core Imports
```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from openai import AsyncOpenAI
```

### Entry Point Pattern
```python
app = FastAPI()
client = AsyncOpenAI()

class FileMetadata(BaseModel):
    category: str
    confidence: float

@app.post("/api-01/classify", response_model=FileMetadata)
async def classify_file(content: str):
    response = await client.beta.chat.completions.parse(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": f"Classify this: {content}"}],
        response_format=FileMetadata,
    )
    return response.choices[0].message.parsed
```

### Key Abstractions
| Concept | What It Is | When You Use It |
|---------|-----------|-----------------|
| FastAPI Router | Endpoint grouping | For API-01 to API-04 segregation |
| Structured Outputs | OpenAI parsing feature | To guarantee JSON matches Pydantic |

### Common Pitfalls
1. Blocking the event loop with synchronous OpenAI calls in an `async def` endpoint.
2. Failing to handle OpenAI API rate limits and timeouts.
3. Not validating the input string length, leading to token limit errors.

### Recommended Project Structure
```
project/
├── api/
│   ├── routes.py
│   └── models.py
├── services/
│   └── ai_service.py
└── main.py
```

## 4. Implementation Guidance

**Model Configuration:**
- Model: gpt-4o-mini (cost-effective for classification)
- Temperature: 0.1 (low temperature for deterministic classification)

**Core Pattern:**
Controller (FastAPI) -> Service (AI processing) -> OpenAI API (Structured Output) -> Response.

**Context Window Strategy:**

## 4b. AI Systems Best Practices

> Written by `gsd-ai-researcher`. Cross-cutting patterns every developer building AI systems needs — independent of framework choice.

### Structured Outputs with Pydantic

Use Pydantic to define the exact schema. FastAPI uses this for the HTTP response, and OpenAI uses it for the model output.

```python
class ClassificationResult(BaseModel):
    file_type: str
    suggested_folder: str
    is_sensitive: bool
```

### Async-First Design

Use `AsyncOpenAI` client. Never use the synchronous `OpenAI` client within an `async def` FastAPI endpoint, as it will block the ASGI event loop and degrade concurrency.

### Prompt Engineering Discipline

Keep system prompts isolated in a separate configuration file or constant block. Use strict few-shot examples for file classification.

### Context Window Management

Implement a token counting utility (e.g., `tiktoken`) to ensure the request body does not exceed the model limit. Truncate safely at paragraph boundaries.

### Cost and Latency Budget

Expected cost per call < $0.001. Target latency < 1500ms. Use fallback to heuristic logic if the AI API times out.
