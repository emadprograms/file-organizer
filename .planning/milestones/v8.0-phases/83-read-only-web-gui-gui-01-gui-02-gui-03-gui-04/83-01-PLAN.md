  <files>src/web/app.js</files>
  <action>
    Create `src/web/app.js` to handle data fetching and DOM updates.
    - Fetch `http://127.0.0.1:8000/api/houses` to populate a house selector in the sidebar.
    - On house selection, fetch `http://127.0.0.1:8000/api/houses/{house_id}/categories` for dashboard stats (GUI-02).
    - Fetch `http://127.0.0.1:8000/api/houses/{house_id}/timeline` to render the chronological timeline of documents (GUI-03).
    - Implement a function `viewDocument(houseId, vaultId)` that sets the `src` of an `<iframe>` in `#pdf-viewer` to `http://127.0.0.1:8000/api/houses/{house_id}/pdf/{vault_id}` (GUI-04).
    - Handle empty states gracefully using the exact text: `There are no documents in this category. Ingest documents via the CLI to view them here.`
    - Handle errors using the exact text: `Error Loading Data — Please refresh the page or check the backend connection.`
    - Call `lucide.createIcons()` after DOM updates.
