## Milestone Summary

**Key Decisions:**
- Decision: Use a single unified `state.json` file per house instead of 3 disconnected files. (Rationale: Avoid state sync issues and orphans when paths change).
- Decision: Base timeline document prefixes on cumulative page indices rather than sequential document numbering. (Rationale: Provides implicit page length context to the user).
