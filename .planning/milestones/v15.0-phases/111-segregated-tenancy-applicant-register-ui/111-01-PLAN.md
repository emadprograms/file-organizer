# Phase 111: Segregated Tenancy & Applicant Register UI - Plan

**Phase:** 111
**Goal:** Split the House Profile into two distinct visual sections (Residents vs Applicants / Unfulfilled Allocations), style applicant cards with clipboard iconography, `📋 متقدم (لم يسكن)` badge, application date, document count, and notes, and wire click navigation to applicant category folders.
**Requirements:** REG-01, REG-02, REG-03

---

## Tasks

### Task 1: Update House Profile Component (`house-profile.js`)
- In `src/HousingApplication.Web/wwwroot/js/house-profile.js`:
  - In `loadHouseProfile`:
    - Format stats badge to distinguish residents and applicants when applicants exist.
  - In `renderHouseProfile(profile)`:
    - Partition `profile.tenants` into `residents` (`is_resident !== 0`) and `applicants` (`is_resident === 0`).
    - **Section 1: Resident Tenants (`residents-section`)**:
      - Render header: `المستأجرون المقيمون` with resident count badge.
      - Render existing resident cards (`.tenant-profile-card`) with tenure colors and duration badges.
      - If `residents.length === 0`, show empty residents state ("لا يوجد مستأجرون مقيمون مسجلون لهذا المنزل حالياً.").
    - **Section 2: Applicants & Unfulfilled Allocations (`applicants-section`)**:
      - If `applicants.length > 0`:
        - Render divider and section header: `سجل المتقدمين وطلبات التخصيص` with count badge.
        - For each applicant:
          - Construct `.applicant-profile-card.tenant-profile-card` with dashed border and purple theme.
          - Render clipboard avatar icon.
          - Render `📋 متقدم (لم يسكن)` badge (`.applicant-badge`).
          - Render application/allocation order date: `طلب / تخصيص: ${sDate}`.
          - Render document count and category count badges.
          - Render notes tag (`.applicant-notes`) if `t.notes` is present.
          - Wire click event to navigate to `#/area/{area}/house/{house}/tenant/{house}_{applicantName}`.

### Task 2: Automated Frontend Tests (`tests/frontend/components/house_profile.test.js`)
- Add tests covering:
  - Rendering segregated sections: both `المستأجرون المقيمون` and `سجل المتقدمين وطلبات التخصيص` present when both exist.
  - Applicant card rendering: includes `.applicant-profile-card`, `📋 متقدم (لم يسكن)`, application date, document count, and optional notes.
  - Click navigation on applicant card: updates `window.location.hash` to applicant's tenant folder route.
  - House with only applicants: shows empty resident message and populates applicant cards.
  - House with only residents: renders resident cards and omits applicants section.

### Task 3: Regression Verification
- Run `npm run test:frontend` (all tests pass).
- Run `export PATH="$HOME/.dotnet:$PATH" && dotnet test HousingApplication.sln` (all tests pass).
