# Requirements: Milestone v16.0 Settings Streamlining & Applicant Alignment

## Milestone v16.0 Goals

Simplify the House Settings modal by eliminating redundant notes inputs, rebalancing the tenant management table to a clean 12-column grid, removing notes display badges from applicant cards in the House Profile, and ensuring non-residing applicants are exempt from vacated tenant conflict prompts.

## Requirements

### Settings Modal Simplification (SET)
- [x] **SET-01**: Remove the `Notes` column and input from the House Settings modal (`#tenant-modal` in `index.html` and `tenant-manager.js`), rebalancing table columns to 12 clean spans:
  - Tenant Name: `sm:col-span-4`
  - Tenant Type (Resident / Applicant): `sm:col-span-2`
  - Start Date / Application Date: `sm:col-span-2`
  - End Date: `sm:col-span-2`
  - Present Checkbox: `sm:col-span-1`
  - Delete Button: `sm:col-span-1`
- [x] **SET-02**: Ensure smooth two-way switching between `Resident` (`is_resident = 1`) and `Applicant` (`is_resident = 0`) in `#tenant-modal`:
  - Switching to Applicant unchecks and disables `Present`, clears and disables `End Date` (`N/A (لم يسكن)`), and updates Start Date label/title to `Application / Order Date • تاريخ الطلب/التخصيص`.
  - Switching to Resident re-enables `Present` and `End Date` and restores the standard Start Date title.
- [x] **SET-03**: Remove the `.applicant-notes` badge from applicant cards in House Profile (`house-profile.js`), keeping the applicant card focused on identity, application/decree date, document count, and folder count.

### Vacancy & Date Validation (VAC)
- [x] **VAC-01**: Safeguard backend vacated tenant date conflict validation in `Program.cs` so that applicants (`IsResident == 0`) are explicitly exempt from vacate date conflict prompts during document ingestion.

### Verification & Testing (VER)
- [x] **VER-01**: Update frontend Vitest test suite (`tests/web/components/house_settings_modal.test.js`, `tests/web/components/applicant_workflow.test.js`, and `tests/web/components/house_profile.test.js`) to assert the absence of `.tenant-notes-input` and `.applicant-notes`, verifying 100% test pass.
- [x] **VER-02**: Verify all backend xUnit tests (`tests/HousingApplication.Tests/`) and Vitest frontend suites pass with zero regressions.
