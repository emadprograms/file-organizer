# Milestone v13.0 Audit: Decoupled Monorepo Architecture & Native ASP.NET Core Web Server

## Executive Summary

Milestone v13.0 successfully decoupled the user-facing web dashboard and document query operations from the Python runtime into a native, high-performance ASP.NET Core 8.0 Minimal API web application located in `web-net/`. The web server shares only `organizer.db` (SQLite in WAL mode) and the clean disk vault (`{area}/{house}/vault/`), serving the existing vanilla JS/HTML frontend from `wwwroot/` with 100% JSON contract parity. A self-contained Windows single-file executable (`FileOrganizer.Web.exe`) has been built, packaged, and verified for zero-dependency deployment in restricted enterprise Windows server environments.

## 3. Cross-Stack Integration & Architecture Deliverables

1. **Decoupled Monorepo Architecture**:
   - Web application runs entirely within `web-net/` with native C# 12 / .NET 8.
   - Zero invocation of `python`, `.venv`, or Python packages during web server execution or manual document ingestion.
   - SQLite WAL mode ensures safe, high-throughput concurrent access between Python batch jobs and .NET web requests.

2. **API & Model Parity**:
   - `GET /api/tree`: Hierarchical area/house tree with tenure badges (`short`, `medium`, `long`).
   - `GET /api/houses`: Area & house summaries with metrics.
   - `GET /api/areas/{area}/houses/{house}/timeline`: Multi-tenant chronological timeline.
   - `GET /api/areas/{area}/houses/{house}/categories`: Folder breakdowns with vault documents.
   - `GET /api/search`: Global search across houses, tenants, and documents.
   - Database tables `documents` and `tenants` match 1:1 with C# records and SQLite PRAGMA table info.

3. **Static File Serving & Zero Frontend Rewrite**:
   - Existing HTML/CSS/JS frontend served directly from `wwwroot/`.
   - MIME types strictly preserved (`text/html`, `text/javascript`, `text/css`).
   - 61 Vitest tests verify frontend UI behaviors without needing any frontend modifications.

4. **Windows Single-File Distribution & Production Deployment**:
   - Published standalone binary `dist/win-x64/FileOrganizer.Web.exe` bundled with .NET 8 runtime and SQLite engine.
   - Ready-to-use IIS In-Process hosting `web.config`.
   - Complete deployment documentation in `web-net/DEPLOYMENT-WINDOWS.md` covering standalone CLI execution, native Windows Service (`sc.exe`), IIS In-Process, firewall rules, and SQLite WAL file permissions.
