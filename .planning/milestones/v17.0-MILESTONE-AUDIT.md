## 1. Executive Summary

Milestone v17.0 implemented end-to-end user authentication, session management, and strict role-based access control (RBAC):
- **User Store & PBKDF2 Security**: Idempotent SQLite `users` table, PBKDF2 HMAC-SHA256 password hashing with 10,000 iterations and 16-byte cryptographically secure salt. Auto-seeds 10 predefined users on startup.
- **Strict Role Boundaries**:
  - **Full Access (Admin)**: `Emad`, `Bubshait`, `Ehtezaz`, `Mustafa` retain full operational capabilities including document, batch, page, custom folder, and house deletion.
  - **Read & Upload Only (Contributor)**: `Nawaf`, `Naseem`, `Mulla`, `Mariam`, `Shaima`, `Mona` have upload and read access, and are strictly barred from deleting any content.
- **Backend Protection**: All deletion endpoints (`DELETE .../documents/{vault_id}`, `POST .../batch-delete`, `POST .../delete-pages`, `DELETE .../houses/{house}`) return `403 Forbidden` if invoked by a Contributor.
- **Frontend UI Masking**: Dedicated bilingual Login Screen (`#login-screen`), top navbar active user indicator (`#user-profile-wrapper`) with avatar initials and role badge, and dynamic masking of all delete controls across Categories, Timeline, Document Action Modal, Merge Modal, Document Page Editor, and House Settings Danger Zone.
- **Multi-Stack Parity**: 100% static asset synchronization between `src/HousingApplication.Web/wwwroot/` and `dist/win-x64/wwwroot/`.

All **18 requirements** across **AUTH**, **RBAC**, **UI**, **PERM**, and **VER** categories have been verified and validated with 100% passing tests (970 .NET xUnit and 563 Vitest tests).
