# Quick Task 260914-aq4: Right side light grey placeholder with document preview guidance when entering a house

## Overview
When entering any house in the dashboard, the right-side panel was previously an empty blank white space because both `document-viewer-panel` and `welcome-panel` were hidden without an active document selected. This quick task adds a dedicated `#document-empty-state` component with a calm light grey background (`#edf0f4` in light mode, `#080c14` in dark mode) and clear bilingual guidance explaining that clicking any PDF or document from the list opens it in the preview area.

## Tasks
1. **HTML & CSS Architecture**: Add `#document-empty-state` container to `index.html` (and sync to `dist/win-x64/wwwroot/index.html`) with light grey background rules in `styles.css` (both source and dist).
2. **View Controller & Router Integration**: Update `router.js`, `doc-viewer.js`, and `area-grid.js` so that when a house is selected and no document is active (or when a document is closed), `#document-empty-state` is visible, and when a document is opened, it is hidden.
3. **Automated Testing**: Create Vitest tests in `tests/web/components/document_empty_state.test.js` validating visibility, copy, styling, and transitions across house entry, document open, and document close.
