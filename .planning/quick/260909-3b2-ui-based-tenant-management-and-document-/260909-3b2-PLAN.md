# Quick Task: UI-Based Tenant Management and Document Reallocation

## Description
Provide full UI and API capabilities to manage tenant timelines (names, start dates, end dates) directly from the dashboard, and automatically reallocate documents according to the system's strict priority rules:
1. **Explicit Name Priority**: If a document (or any of its pages) explicitly names a tenant, it stays with that tenant regardless of the date.
2. **Date-Range Fallback**: Unnamed documents (such as utility bills or generic notices) are reallocated according to the tenant tenure timeline (`start_date` to `end_date`).
3. **Manual Document Override**: Users can also manually assign an individual document to any tenant directly from the UI.

## Tasks
1. **Repository & Reallocation Engine (`src/db/repository.py`)**
   - Add `update_tenant`, `delete_tenant`, and `reallocate_house_documents(house_id)`.
   - Ensure `reallocate_house_documents` inspects page-level `expected_tenant_name` to preserve explicit tenant ownership over date windows.
   - Update `documents.tenant_id` and `pages.tenant_id` atomically.

2. **FastAPI Endpoints (`src/api/routes.py`)**
   - `GET /api/areas/{area_id}/houses/{house_id}/tenants`: Fetch all tenants for a house.
   - `POST /api/areas/{area_id}/houses/{house_id}/tenants`: Bulk save tenant list (add/update/delete) and trigger automatic reallocation.
   - `POST /api/areas/{area_id}/houses/{house_id}/reallocate`: Re-run reallocation on demand.
   - `PATCH /api/areas/{area_id}/houses/{house_id}/documents/{vault_id}/tenant`: Manually reassign a specific document to a tenant.

3. **Dashboard Web UI (`src/api/static/index.html`)**
   - Add a "Manage Tenants" button in the house view header and timeline section.
   - Build an intuitive modal dialog to view, edit, add, and remove tenants with date pickers.
   - Include a clear explanatory note about name-first vs. date-range priority.
   - Add a "Save & Reallocate" action that sends updates to the API and refreshes the timeline and categories dynamically.
   - Allow changing tenant assignment on document detail/cards.

4. **Testing & Verification**
   - Create `tests/test_tenant_reallocation_api.py` covering tenant CRUD, automatic date-range reallocation, name-priority preservation, and manual document overrides.
   - Run test suite with pytest.
