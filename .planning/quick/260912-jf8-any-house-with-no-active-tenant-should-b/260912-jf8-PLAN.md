# Quick Task 260912-jf8: Vacant House Grey Styling and Remove False Active Tenant Fallback

## Problem
When a house has no active tenant (all tenants vacated/ended in past years, e.g. 2024), the backend fell back to `activeTenant = hTenants[0]` and forced tenure duration calculation as if the past tenant were still residing. This erroneously set `house.current_tenant` to the past tenant and calculated `duration_category = "long"` (red border and `> 10 Yrs` badge) based on their start date. In addition, the frontend in `area-grid.js` had a fallback `(idx === 0 && !t.subtitle?.includes('-'))` that highlighted the first past tenant with colored backgrounds/icons if their subtitle was a single year (e.g. `2024`), and rendered the tenure badge with `Unknown` when duration category was null.

## Scope of Fixes
1. **Backend .NET (`web-net/Data/FileOrganizerRepository.cs`)**:
   - In `GetTreeAsync`: Remove fallback `if (activeTenant == null && hTenants.Count > 0) activeTenant = hTenants[0];`. When no tenant is active, `activeTenant`, `CurrentTenant`, and `DurationCategory` remain `null`, and past tenants keep `isActive = false`, `DurationCategory = null`, and subtitle without `Present`.
   - In `GetHouseCardsAsync`: Remove fallback `if (activeTenant == null && hTenants.Count > 0) activeTenant = hTenants[0];`. When no tenant is active, `ActiveTenant` and `DurationCategory` remain `null`, and `TenureColor` is `"grey"`.
   - In `GetHouseProfileAsync`: `ActiveResident = activeTenant?.Name;` (do not fall back to `tenantProfiles.FirstOrDefault()?.Name`).
2. **Backend Python (`src/api/routes.py`, `src/presentation/export_static.py`, `scripts/export_web.cjs`)**:
   - In `get_tree` (routes.py): Remove fallback `if not active_t and h_tenants: active_t = h_tenants[0];`. Keep `active_tenant = None`, `duration_category = None`.
   - In filesystem-fallback `get_tree`: Only set `active_tenant` if `tenant_is_present.get(...)` is true.
   - In `export_static.py` and `export_web.cjs`: Only set `active_tenant` if tenant is present.
3. **Frontend Area Grid (`src/api/static/js/area-grid.js`)**:
   - Set default house card border to grey (`border-l-[5px] border-l-slate-300 dark:border-l-slate-600 hover:border-slate-400`).
   - Set default tenure badge to grey (`bg-slate-100 dark:bg-slate-800 text-slate-500 dark:text-slate-400 border-slate-200 dark:border-slate-700 font-medium`) and badge label to `Vacant` instead of `Unknown`.
   - Remove `|| (idx === 0 && !t.subtitle?.includes('-'))` so past tenants are never falsely marked `isCurrent`.
   - Synchronize across `web-net/wwwroot/js/area-grid.js` and `dist/win-x64/wwwroot/js/area-grid.js` with 0 diff.
4. **Testing**:
   - Add unit test in `web-net/FileOrganizer.Tests/RepositoryTests.cs` for vacant house (no active tenant) returning `DurationCategory == null`, `TenureColor == "grey"`, and `CurrentTenant == null`.
   - Add unit test in `tests/frontend/components/area_grid_card.test.js` verifying vacant house card has grey border, "Vacant" badge, and past tenant styling.
   - Verify all Vitest, xUnit, and pytest test suites pass.
