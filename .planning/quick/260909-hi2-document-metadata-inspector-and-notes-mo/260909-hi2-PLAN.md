# Quick Task: Document Metadata Inspector & Notes Modal on Spacebar

## Description
Transform the Spacebar modal and card icon into a rich macOS-style Document Inspector & Notes workspace. Eliminate the redundancy of duplicate PDF viewports, allow users to inspect SQLite database metadata and attach custom notes directly to documents, highlight documents with notes in warm yellow, and auto-expand folders containing noted documents when opening a tenant:

1. **Database & API for Document Notes & Metadata**:
   - Add `notes TEXT` to `documents` table in `src/db/schema.py` with automatic migration in `init_db`.
   - Update `Document` model in `src/db/models.py` and `src/api/models.py`.
   - Add `PATCH /api/areas/{area_id}/houses/{house_id}/documents/{vault_id}/notes` endpoint.
   - Add `GET /api/areas/{area_id}/houses/{house_id}/documents/{vault_id}/metadata` endpoint (returning document metadata, notes, and page-level OCR/AI extraction intel).
   - Ensure categories and timeline endpoints return `notes` on each document.

2. **Document Inspector & Notes Modal (`#quick-look-modal` / `#doc-inspector-modal`)**:
   - Redesign the modal into a sleek macOS "Get Info" inspector sheet with:
     - Document Title & Filename
     - Category, Tenant, Date, and 🔒 Manual Pin badges
     - File info (page count, vault ID)
     - Extracted page intel (subject, sender, receiver, summary)
     - Interactive Notes textarea with live saving and database sync
   - Triggerable via `Spacebar` on any hovered/selected document and via the `ℹ️` Info button on document cards.
   - Pressing `Esc` or clicking outside closes the modal.

3. **Yellow Highlighting & Auto-Expanding Folders**:
   - Any document with non-empty `notes` is highlighted in warm yellow (`border-l-4 border-l-amber-400 bg-amber-50/70 border-amber-200`) with a `📝 Note` badge.
   - When opening a tenant's categories view, any folder containing a document with notes automatically opens/expands so the highlight is immediately visible.

4. **Testing & Verification**:
   - Add integration tests for updating document notes and fetching metadata.
   - Add Vitest frontend tests for Spacebar opening the inspector, notes saving, yellow highlighting, and auto-expanding folders.
