# Quick Task: Multi-Select Drag and Drop for Tabs (Tablets) & Computers (Desktop)

## Overview
Enable multi-document drag and drop when users select multiple documents using checkboxes (batch multi-select):
1. **Computers (Desktop HTML5 Mouse Drag):** When dragging a selected document, all selected documents are dragged together, visually dimmed across the DOM, and dropped onto category folders or sidebar tenants using the `/documents/batch-move` API, followed by DOM updates and selection clearing.
2. **Tabs (Tablet Touchscreen Drag):** When pressing and holding (>=280ms) a selected document, activate multi-touch drag with an avatar displaying the count pill, dim all selected documents, highlight target folders, and drop all documents via batch move.

## Tasks

### Task 1: Multi-Select Drag & Drop Implementation in doc-manager.js & categories-view.js
- In `src/api/static/js/doc-manager.js`:
  - Enhance `handleDocDragStart` to detect if the dragged doc is in `window.selectedDocIds` (or `selectedDocIds`). If so, record `draggedDoc.vault_ids` with all selected IDs, `draggedDoc.isMulti = true`, and dim all selected items.
  - Enhance `handleDocDragEnd` to un-dim all selected documents and reset `draggedDoc`.
  - Enhance `handleCategoryDrop` to call `POST .../documents/batch-move` when multiple documents are dragged, update all in DOM via `moveDocInDom`, deselect all docs, and display a count-aware toast.
  - Enhance `handleTenantTreeDrop` to assign all dragged documents when multi-selected.
- In `src/api/static/js/categories-view.js`:
  - In `startTouchDrag`: Check if `selectedDocIds.has(state.doc.vault_id)`. If so, include all selected IDs in `state.vault_ids`, dim all selected elements, and render the count badge in `#touch-drag-avatar`.
  - In `cancelTouchDrag`: Un-dim all selected documents.
  - In `finishTouchDrop`: Support multi-document drops, passing to `handleCategoryDrop` or moving each document in DOM and deselecting.
- Synchronize updated JS files with `web-net/wwwroot/js/` and `dist/win-x64/wwwroot/js/`.
