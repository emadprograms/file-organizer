## 3. Dual-Backend Parity (FastAPI vs ASP.NET Core 8.0 Minimal APIs)

Both backend runtimes provide identical functionality, JSON response contracts, status codes, and database transactions:

1. **House Archive ZIP Export**:
   - FastAPI: `GET /api/areas/{area}/houses/{house}/export-zip` using Python's `zipfile` and `StreamingResponse`.
   - ASP.NET Core: `GET /api/areas/{area}/houses/{house}/export-zip` using `System.IO.Compression.ZipArchive` and `Results.File`.
2. **Batch Move & Batch Delete**:
   - FastAPI: Atomic SQLite transaction updating category values or cascading document/page deletion with vault disk unlinking.
   - ASP.NET Core: Atomic Dapper transaction using `repo.BatchMoveDocumentsAsync` and `repo.BatchDeleteDocumentsAsync` with physical file cleanup.
3. **House Creation & Directory Scaffolding**:
   - FastAPI: `POST /api/areas/{area}/houses` creating `{area}/{house}/batches` and `{area}/{house}/vault` directories, inserting house record, and optional tenant.
   - ASP.NET Core: `POST /api/areas/{area}/houses` matching DTO and disk initialization.
4. **Static Asset Parity**:
   - Zero difference verified between `src/api/static/` and `web-net/wwwroot/` via `diff -r src/api/static/ web-net/wwwroot/`.
