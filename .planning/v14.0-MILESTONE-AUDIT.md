# Milestone v14.0 Audit: Power-User Operations & Portfolio Expansion

## Executive Summary

Milestone v14.0 successfully equipped the digital archive management system with advanced operational tooling, power-user capabilities, and portfolio management:
1. **One-Click House Archive Export & Chronological Dossier (Phase 105 + Quick Refinements QCK-01, QCK-03, QCK-04, QCK-06)**:
   - **Categorized ZIP Archive Export (Phase 105)**: Full house digital archive packaging into streamed ZIP archives (`GET /api/areas/{area}/houses/{house}/export-zip`) with collision-free clean Arabic filenames (`{folder_index}_{title}.pdf`) across both FastAPI and ASP.NET Core backends.
   - **Standard 2-Digit Folder Numbering Fix**: `FOLDER_PREFIXES` normalization ensuring every category folder in the ZIP has its canonical two-digit prefix (e.g., `01 - `, `05 - `, `06 - `), resolving unnumbered folder issues.
   - **Interactive Export Options Modal (`#export-archive-modal`, QCK-01)**: Modal dialog with dual selectable Format Cards (Format Card A: Categorized ZIP Archive; Format Card B: Combined Chronological PDF Dossier) and Tenancy Scope Filter (All Tenants / Full House vs Individual active/past tenant).
   - **Combined Chronological PDF Dossier**: Single merged PDF export (`GET /api/areas/{area}/houses/{house}/export-pdf`) implemented via PyMuPDF in Python and PdfSharpCore in ASP.NET Core 8.0.
   - **Descending Chronological Sort (QCK-03)**: Orders documents from newest to oldest so Page 1 presents the most recent document, followed by older historical records, with undated documents placed at the end.
   - **Minimalist 3-Column Running Footer (QCK-03)**: Rendered on every page of the generated PDF dossier:
     - Bottom-Left: Document primary filing date (`YYYY-MM-DD`), blank if undated.
     - Bottom-Center: Category name with 2-digit number prefix preserved (e.g. `05 - عقود`, `06 - كهرباء وماء`).
     - Bottom-Right: Group & Master pagination `X/Y  (Z)` (e.g. `1/3  (14)`).
     - Typography & Layout: 7.5 pt muted slate gray (`#64748b`), 16 pt margin. Zero verbose labels (no "Date:", "Category:", "Page:").
   - **Arabic Cursive Text Shaping & BiDi Visual Reordering (QCK-04)**:
     - Python FastAPI (`src/api/routes.py`): Integrated `arabic-reshaper` + `python-bidi` (`get_display(arabic_reshaper.reshape(cat))`) preventing disjointed "terminal Arabic" isolated characters, and computing shaped text widths for exact centered alignment.
     - ASP.NET Core 8.0 (`web-net/Common/ArabicReshaper.cs` & `web-net/Program.cs`): Engineered a zero-dependency pure C# `ArabicReshaper.ReshapeAndReorder` mapping standard Arabic characters (`\u0600`–`\u06FF`) to Unicode Presentation Forms-B (`\uFE80`–`\uFEFC`), supporting dual-joining letters, right-joining letters, Lam-Alef ligatures (`لا`, `لأ`, `لإ`, `لآ`), reversing Arabic character and word runs while preserving LTR numeric tokens (`05 - `) and mirroring bracket punctuation.
   - **Export Button Relocation & Bottom Archive Summary Removal (QCK-06)**: Removed the confusing and redundant digital archive summary section (`بيانات الأرشيف الرقمي للمنزل`) from the bottom of the House Profile, eliminating visual clutter below the tenant list. Relocated the Export House Archive button (`#btn-export-house-archive`) to the top Document Panel header right beside `#btn-manage-tenants` for 0-scroll permanent visibility across Profile, Folders, and Timeline views with full backward compatibility.
2. **Multi-Select Batch Document Operations (Phase 106 + Quick Refinements QCK-02, QCK-08)**:
   - Multi-select checkbox UI on document cards, folder-level toggle, and global Select All / Deselect All.
   - Glassmorphism dark floating action dock (`#batch-action-bar`) with dynamic selection counter and action buttons (`[ Move Selected ]`, `[ Copy Selected ]`, `[ Delete Selected ]`, `[ Deselect ]`).
   - Atomic Batch Move (`POST .../batch-move`): Relocates selected documents to target standard or custom folder in a single atomic transaction with optional target tenant reassignment (`target_tenant_id`).
   - Cascade Batch Delete (`POST .../batch-delete`): Cascade deletion from SQLite and vault disk storage with confirmation modal.
   - Multi-Select Batch Copy (`POST .../batch-copy`): Duplicates document references into an additional category folder for immediate cross-referencing with optional target tenant reassignment (`target_tenant_id`).
   - **Batch Tenant Selection & Remove Copy Note (QCK-08)**: Removed explanatory amber note from `#batch-copy-modal` without replacement; added Target Tenant selector (`المستأجر • Target Tenant`) to both Move and Copy modals defaulting to `🏛️ المستأجر الحالي للوثيقة • Same Tenant`; cleaned button labels to `Move Documents` and `Copy Documents`; supported `target_tenant_id` end-to-end across FastAPI and ASP.NET Core.

## 3. Dual-Backend Parity (FastAPI vs ASP.NET Core 8.0 Minimal APIs)

Both backend runtimes provide identical functionality, JSON response contracts, status codes, and database transactions:

1. **House Archive Export (ZIP & Chronological PDF Dossier)**:
   - FastAPI: `GET /api/areas/{area}/houses/{house}/export-zip` and `GET /api/areas/{area}/houses/{house}/export-pdf` using Python `zipfile` and PyMuPDF `fitz`.
   - ASP.NET Core: `GET /api/areas/{area}/houses/{house}/export-zip` and `GET /api/areas/{area}/houses/{house}/export-pdf` using `System.IO.Compression.ZipArchive` and `PdfSharpCore`.
   - Both support optional `tenant_id` filtering, 2-digit folder prefix normalization (`FOLDER_PREFIXES`), and descending chronological sorting.
2. **Arabic Text Shaping & BiDi Visual Reordering Parity**:
   - FastAPI: In `src/api/routes.py`, passes category names through `arabic_reshaper.reshape` and `get_display` from `bidi.algorithm`, then queries font string width for centered positioning on the PDF page.
   - ASP.NET Core: In `web-net/Program.cs`, calls `ArabicReshaper.ReshapeAndReorder(catName)` and measures string width with `gfx.MeasureString(catShaped, footerFont)`. The pure C# `ArabicReshaper.cs` maps standard Arabic characters to Unicode Presentation Forms-B (`\uFE80`–`\uFEFC`), dynamically detecting isolated, initial, medial, and final forms, handling Lam-Alef ligatures (`لا`, `لأ`, `لإ`, `لآ`), reversing RTL Arabic runs, while keeping LTR numeric tokens (`05 - `) intact.
   - Both engines output identical visual presentation forms, eliminate disconnected letters, and preserve 2-digit category prefixes.
3. **Multi-Select Batch Move, Batch Delete, & Batch Copy**:
   - FastAPI: Atomic SQLite transaction updating category values, cascading document/page deletion with vault disk unlinking, and `batch_copy_documents` setting `is_timeline_visible = 0`.
   - ASP.NET Core: Atomic Dapper transaction using `repo.BatchMoveDocumentsAsync`, `repo.BatchDeleteDocumentsAsync`, and `repo.BatchCopyDocumentsAsync` with physical file cleanup and timeline de-duplication.
4. **Database Schema Parity & Automatic Migrations**:
   - Both Python (`src/db/schema.py`) and C# (`web-net/Data/DatabaseInitializer.cs`) maintain identical schema DDL including `is_timeline_visible INTEGER DEFAULT 1` with auto-migration checks on startup.
   - Timeline queries in both backends filter out copy duplicates with `(d.is_timeline_visible IS NULL OR d.is_timeline_visible = 1)`.
5. **House Creation & Directory Scaffolding**:
   - FastAPI & ASP.NET Core: `POST /api/areas/{area}/houses` creates `{area}/{house}/batches` and `{area}/{house}/vault` directories, inserts house record, handles duplicate conflict (409), and creates optional initial tenant.
6. **Single Document Update & Inline Renaming**:
   - Both backends support `PATCH /api/areas/{area}/houses/{house}/documents/{vault_id}` with `{ "arabic_title": "..." }`, validating area and house constraints, updating `brief_arabic_title` and `filename` in SQLite, and returning the updated document model.
7. **Static Asset Parity**:
   - Zero difference verified between `src/api/static/` and `web-net/wwwroot/` via `diff -ru src/api/static/ web-net/wwwroot/`.
